How a day works

Yesterday's app, today's TODOs

Every day's folder has a starter and a solution with the same tests. When the tests pass, the day is done and the app still runs.

  1. Read the night

    Each day opens at the gate: a queue, a dropped connection, a power cut. That's what today's code is for.

  2. Run the starter's tests

    ../../mvnw test fails on purpose. The test names say what the gate should do.

  3. Fill in the TODOs

    Step by step, each one marked in the code. After every step, more tests go green.

  4. Check, then commit

    Tick the day's checklist here, compare with solution/, and commit your work.

The route

Six phases, one app

From Day 101 to Day 130. The app you finish each phase with is the one the next phase starts from.

    What you need

    A JDK and an editor

    For people who finished Part 1, 100 Days of Java. Everything runs on your laptop.

    A JDK, version 21 or newer

    Temurin 21 from adoptium.net, or your system's package manager. Check with java -version.

    Maven, already included

    The Maven wrapper (mvnw, mvnw.cmd) downloads the right version the first time you run it.

    An editor

    IntelliJ IDEA Community, VS Code with the Java extensions, or Eclipse. Open a day's starter/pom.xml.

    Git

    To keep your own daily commits. Optional: Scene Builder from Day 106, a USB scanner for Day 110, Docker for Day 124.

    The gate opens at Day 101

    A Maven project with four modules, tests that run, and CI. About 2 to 3 hours.
