Every requirement the gate has becomes a day

Kilele Nights runs from 18:00 to 04:00 on Saturday 14 November. One laptop at the gate, a queue, a USB scanner, venue Wi-Fi that drops every few minutes, and power that may go out mid-sale. Regular is KES 1,500 (500 places), VIP KES 5,000 (50).

  • Remember every sale on its own disk, with no server104
  • Let the organiser's guest list in, and print the night's report105
  • Be fast at the gate: keyboard only, and USB scanners that type like a keyboard108110
  • Never freeze, even on a slow old laptop109
  • Never half-save a sale when the power goes111

Yesterday's app, today's TODOs

Every day's folder has a starter and a solution with the same tests. When the tests pass, the day is done and the app still runs.

Read the night

Each day opens at the gate: a queue, a dropped connection, a power cut. That's what today's code is for.

Run the starter's tests

../../mvnw test fails on purpose. The test names say what the gate should do.

Fill in the TODOs

Each one is marked in the code with its step. After every step, more tests go green.

Check, then commit

Tick the day's checklist here, compare with solution/, and commit your work.

Six phases through one night

From Day 101 to Day 130, coloured from sunset to 04:00. The app you finish each phase with is the one the next phase starts from.

    A JDK and an editor

    For people who finished Part 1, 100 Days of Java. Everything runs on your own laptop.

    A JDK, 21 or newer

    Temurin 21 from adoptium.net, or your system's package manager. Check with java -version.

    Maven, included

    The Maven wrapper (mvnw, mvnw.cmd) downloads the right version the first time you run it.

    An editor

    IntelliJ IDEA Community, VS Code with the Java extensions, or Eclipse. Open a day's starter/pom.xml.

    Git

    To keep your own daily commits. Optional: Scene Builder from Day 106, a USB scanner for Day 110, Docker for Day 124.

    The gate opens at Day 101

    A Maven project with four modules, tests that run, and CI. About 2 to 3 hours.
