Set up once, in about ten minutes

  1. Install a JDK, version 21 or newer, for example Temurin 21 from adoptium.net. Check with java -version.
  2. Get the course: 
    git clone https://github.com/sagebeme/box-office-30-days.git
cd box-office-30-days/day-101-project-skeleton/starter
  3. Run the tests: ../../mvnw test (on Windows, ..\..\mvnw.cmd test). The first run downloads Maven and the libraries, so give it a minute. Some tests fail: that's today's work.
  4. Read the lesson on Day 101 and follow its steps until the tests pass.

To read this site offline, run jwebserver -p 8000 in the course folder (it comes with the JDK) and open http://localhost:8000/site/.
